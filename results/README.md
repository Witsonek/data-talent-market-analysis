# Results

This directory contains final, reviewable outputs generated by the project's analytical stages. Code remains in the tool-specific directories (`sql/`, `python/`, and `power-bi/`), while approved exports and result documentation are stored here.

```text
results/
├── sql/
│   ├── README.md
│   ├── geographic_coverage.csv
│   ├── monthly_posting_trends_by_role.csv
│   ├── role_specific_top_skills.csv
│   └── role_profiles.csv
├── python/
│   └── .gitkeep
└── power-bi/
    └── .gitkeep
```

## SQL results

The SQL stage is complete and contains four validated CSV exports plus a full analytical report:

- [`sql/README.md`](sql/README.md) — English report interpreting the SQL findings, methodology, implications, and limitations;
- [`sql/geographic_coverage.csv`](sql/geographic_coverage.csv) — number of represented countries;
- [`sql/monthly_posting_trends_by_role.csv`](sql/monthly_posting_trends_by_role.csv) — monthly posting counts by standardized role;
- [`sql/role_specific_top_skills.csv`](sql/role_specific_top_skills.csv) — top five visible skill requirements for every role;
- [`sql/role_profiles.csv`](sql/role_profiles.csv) — consolidated demand, skill coverage, remote-work, and salary-disclosure metrics.

Technical query documentation and reproduction instructions are available in [`../sql/README.md`](../sql/README.md).

## Python results

`results/python/` is reserved for final tables, charts, and other validated outputs from the Python analysis stage. The `.gitkeep` file preserves the planned directory while that stage is in development.

## Power BI results

`results/power-bi/` is reserved for final Power BI exports. Dashboard source files and screenshots will remain organized under `power-bi/`, while publication-ready outputs may be added here when the reporting stage is complete.

Only final, reproducible outputs are committed to this directory. Temporary exports, intermediate checks, and helper files are excluded.
